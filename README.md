# 거중기(擧重機) 3D 교육 웹앱

정약용이 설계해 수원 화성 축성(1794~1796)에 쓴 거중기를 3D로 살펴보고 직접 움직여 보는 중학생용 교육 웹앱입니다.
치수는 『화성성역의궤』 권수 도설의 **거중기 전도·분도**를 기준으로 했고, 의궤에 없는 치수는 수원화성박물관 재현품을 참고한 **가정값**으로 표시했습니다.

**바로 열기:** https://parkdongbae.github.io/geojunggi/

설치 없이 `index.html` 파일 하나만 내려받아 열어도 됩니다. three.js가 함께 들어 있어서 인터넷이 없어도 작동합니다.

## 무엇을 배울 수 있나

| 메뉴 | 내용 |
|---|---|
| **시공 순서** | 승량각(다리) → 가로대 → 횡량 → 도르래틀(중유량·하유량) → 소거(얼레 틀) → 밧줄·쇠사슬 순서로 부재가 하나씩 조립됩니다. 단계마다 부재 이름(한자)과 역할을 설명합니다. |
| **과학 원리** | 고정도르래·움직도르래, 축바퀴(얼레)의 원리를 그림과 계산으로 설명합니다. 밧줄 8가닥 → 힘 1/8, 얼레 8배를 곱해 **약 1/64의 힘**으로 돌을 듭니다. |
| **직접 조작** | 왼쪽·오른쪽 얼레를 돌려 돌을 들어 봅니다. 돌 무게(0.3~7.2t)와 일꾼 수를 바꾸면 한 사람이 내는 힘이 계산되고, 양쪽을 다르게 감으면 돌이 기울어집니다. |
| **화성 현장** | 돌에 쇠사슬 걸기 → 들어 올리기 → 유형거(수레) 넣기 → 내려 싣기 → 성벽으로 옮기기 → 녹로로 쌓기까지 60초 장면입니다. |
| **문제 풀기** (패널 아래 버튼) | 8문제 퀴즈입니다. 조작할 때 효과음도 납니다. |

부재를 클릭하면 이름과 설명이 나옵니다. **Ctrl+끌기**로 부재를 떼어 볼 수 있고, 「치수와 자료의 출처」 표에서 모든 치수의 근거를 확인할 수 있습니다.

## 주요 치수

| 항목 | 값 | 근거 |
|---|---|---|
| 승량각(다리) 길이 | 14척 = 4,242mm | 의궤 |
| 전체 높이 | 약 4.4m | Kim 2017 |
| 도르래 | 위 4 + 아래 4 = 8개 | 의궤 |
| 소거 장강 / 단강 | 12척(3,636mm) / 5척(1,515mm) | 의궤 |
| 들 수 있는 무게 | 1만 2천 근(약 7.2t), 장정 30명 | 매일신문·수원시 |
| 단위 환산 | 1척 = 303mm, 1근 = 0.6kg | Kim 2017 |

도르래 지름, 부재 단면 같은 나머지 치수는 가정값이며 앱 안 출처 표에 따로 표시되어 있습니다.

## 개발

```bash
npm install
npm run build   # src/ → index.html (한 파일로 묶음)
npm test        # sim.js 단위 테스트
```

| 파일 | 역할 |
|---|---|
| `src/model_head.js` + `src/model_body.js` | 3D 모델(부재·조립 단계). 빌드할 때 `model.js`로 합쳐집니다. |
| `src/sim.js` | 역학 계산과 화성 현장 장면 시간표(순수 함수, node에서 테스트) |
| `src/app.js` | three.js 화면과 UI |
| `src/template.html` | 페이지 틀·스타일(다크 모드, 모바일 대응) |
| `test/sim.test.mjs` | 힘 계산, 장면 연속성, 돌·수레·가로대 간섭 검사 |
| `PLAN.md` | 설계서와 조사 자료(출처 포함) |
| `ref/` | 같은 방식으로 만든 자격루 앱의 참고 코드 |

좌표는 mm 단위이며 x = 좌우, y = 앞뒤, z = 위입니다.

## 참고 자료

- 『화성성역의궤』(1801) 권수 도설 「거중기 전도·분도」
- 정약용, 「기중가도설(起重架圖說)」, 『여유당전서』
- Kim (2017) — 거중기의 높이·들 수 있는 높이·화성에 쓰인 대수, 척 환산(1척 ≈ 30.3cm). 서지 사항은 `PLAN.md` 1절
- 매일신문(1997.4.23) 「하이테크 문화유산 - 거중기」, 우리역사넷 「정약용의 거중기」, 수원시 e수원뉴스, 경인일보(2009)
