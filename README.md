# 거중기(擧重機) 3D 교육 웹앱

정약용이 설계해 수원 화성 축성(1794~1796)에 쓴 거중기를 3D로 살펴보고 직접 움직여 보는 중학생용 교육 웹앱입니다.
치수는 『화성성역의궤』 권수 도설의 **거중기 전도·분도**를 기준으로 했습니다. 의궤에 길이가 적힌 부재(다리 14척, 소거 장강 12척 등)는 그 길이를 지키고, 나머지 위치와 크기는 **전도 그림의 비율**을 재서 정한 **가정값**으로 표시했습니다.

**바로 열기:** https://parkdongbae.github.io/geojunggi/

설치 없이 `index.html` 파일 하나만 내려받아 열어도 됩니다. three.js가 함께 들어 있어서 인터넷이 없어도 작동합니다.

## 무엇을 배울 수 있나

| 메뉴 | 내용 |
|---|---|
| **시공 순서** | 받침돌 → 승량각(다리) → 가로대 두 단 → 횡량(양끝 고정 도르래) → 중유량·하유량과 쇠사슬 → 소거(얼레 틀, 아래 단 좌우강에 기댐) → 대활륜·얼레축 → 밧줄 → 돌 순서로 부재가 하나씩 조립됩니다. 단계마다 부재 이름(한자)과 역할을 설명합니다. |
| **과학 원리** | 카드를 고르면 **왼쪽 3D에서 거중기가 직접 움직이며** 힘 화살표와 값을 보여 줍니다. 고정 도르래(힘은 같고 방향만 바뀜), 움직·복합 도르래(줄 가닥마다 W/8), 축바퀴(나무살 끝 힘 = 줄 힘 ÷ 8), 일의 원리(h·8h·64h), 좌우 균형과 마찰. 밧줄 8가닥 1/8 × 얼레 1/8 = **약 1/64의 힘**으로 돌을 듭니다. |
| **직접 조작** | 왼쪽·오른쪽 얼레를 돌려 돌을 들어 봅니다(좌우 얼레는 거울처럼 서로 반대로 돎). 돌 무게(0.3~7.2t)와 일꾼 수를 바꾸면 한 사람이 내는 힘이 계산되고, 양쪽을 다르게 감으면 돌이 기울어집니다. |
| **화성 현장** | 돌에 쇠사슬 걸기 → 들어 올리기 → 유형거(수레) 넣기 → 내려 싣기 → 싣고 나와 **성벽 쪽으로 돌아선 뒤** 옮기기 → 녹로 안내까지 60초 장면입니다. |
| **문제 풀기** (패널 아래 버튼) | 8문제 퀴즈입니다. 조작할 때 효과음도 납니다. |

부재를 클릭하면 이름과 설명이 나옵니다. **Ctrl+끌기**로 부재를 떼어 볼 수 있고, 「치수와 자료의 출처」 표에서 모든 치수의 근거를 확인할 수 있습니다.

## 주요 치수

| 항목 | 값 | 근거 |
|---|---|---|
| 승량각(다리) 길이 | 14척 = 4,242mm | 의궤 |
| 전체 높이 | 약 4.4m | Kim 2017 |
| 도르래 | 위 4 + 아래 4 = 8개, 같은 간격(지름 190mm) | 개수=의궤, 크기·간격=전도 비율 |
| 밧줄 | 좌우 2가닥 → 세로 8가닥이 겹치지 않게 내려옴 | 의궤·매일신문 |
| 다리 벌림 | 바닥 x ±1.1m → 꼭대기 x ±0.48m (위가 좁음) | 전도 비율 |
| 가로대(전후강·좌우강) | 두 단, 높이 2.5m·3.15m | 전도 비율 |
| 횡량 | 길이 2m, 양끝에 고정 도르래(위·아래 좌우강을 잇는 밧줄이 걸림) | 전도 |
| 소거 장강 / 단강 | 12척(3,636mm) / 5척(1,515mm). 장강은 바깥 땅에서 아래 단 좌우강에 기댐 | 길이=의궤, 기대는 방식=전도 |
| 대활륜 / 얼레축 | 지름 700mm, 모강 아래 2척 / 지름 150mm, 협강 위 6자. 밧줄은 대활륜 바깥 둘레를 지나 얼레축에 감김 | 위치=의궤·매일신문, 크기=전도 비율 |
| 쇠사슬 | 2개, 하철강에서 돌 앞뒤로 내려가 돌 밑 철강에 걸림 | 의궤·Kim 2017 해석 |
| 들 수 있는 무게 | 1만 2천 근(약 7.2t), 장정 30명 | 매일신문·수원시 |
| 단위 환산 | 1척 = 303mm, 1근 = 0.6kg | Kim 2017 |

부재 단면 같은 나머지 치수는 가정값이며 앱 안 출처 표에 따로 표시되어 있습니다. 가로대 높이는 전도 비율을 따랐기 때문에 「아래 단 약 4자(1.2m)」라는 매일신문 설명과는 다릅니다.

## 개발

```bash
npm install
npm run build   # src/ → index.html (한 파일로 묶음)
npm test        # sim.js 단위 테스트
```

| 파일 | 역할 |
|---|---|
| `src/model_head.js` + `src/model_body.js` | 3D 모델(부재·조립 단계). 빌드할 때 `model.js`로 합쳐집니다. |
| `src/sim.js` | 역학 계산, 밧줄 경로(바퀴 사이 접선 계산), 화성 현장 장면 시간표(순수 함수, node에서 테스트) |
| `src/app.js` | three.js 화면과 UI, 과학 원리 3D 화살표·글자판 |
| `src/template.html` | 페이지 틀·스타일(다크 모드, 모바일 대응) |
| `test/sim.test.mjs` | 힘 계산, 장면 연속성, 돌·수레·가로대 간섭, 밧줄 8가닥 간격, 밧줄이 바퀴 면을 가로지르지 않는지, 유형거 회전 검사 (33개) |
| `PLAN.md` | 설계서와 조사 자료(출처 포함) |
| `ref/` | 같은 방식으로 만든 자격루 앱의 참고 코드 |

좌표는 mm 단위이며 x = 좌우, y = 앞뒤, z = 위입니다.
